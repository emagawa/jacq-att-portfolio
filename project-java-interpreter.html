Interpreter for a Custom Programming Language

Personal Project · Apr 2026

Built a fully functional interpreter in Java — lexer, recursive descent parser, and AST evaluator — supporting variables, control flow, and function calls, with a custom grammar designed from scratch.

What I did

  • Designed a custom grammar for a new programming language from scratch.
  • Wrote a lexer that turns source code into tokens.
  • Built a recursive descent parser that turns tokens into an abstract syntax tree (AST).
  • Implemented an AST evaluator that runs programs, with variables, control flow, and function calls.
